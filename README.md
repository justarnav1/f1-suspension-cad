# F1-Inspired Suspension System

## Overview

A personal CAD project exploring the design and packaging of an F1-inspired suspension system using **Autodesk Fusion 360**.

The **Mercedes-AMG PETRONAS F1 car** was used as a visual and structural reference when studying the overall suspension layout and component placement.

## Project Focus

* Push-rod suspension layout
* Upper and lower wishbones
* Rocker and damper arrangement
* Wheel hub and suspension connections
* Component packaging
* 3D CAD modelling and assembly

## Software

* Autodesk Fusion 360

## Reference

The project was developed using publicly available images and technical references of modern Mercedes-AMG Formula 1 cars. The model is an **independent educational recreation** and is not an official Mercedes-AMG design.

## Learning Outcomes

This project helped me develop a better understanding of mechanical assemblies, component relationships, CAD modelling and the packaging constraints involved in high-performance motorsport.

## Project Files

The repository contains the CAD files, exported model and images of the completed assembly.
